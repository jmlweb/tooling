&gt; TypeScript configuration for React libraries and apps with the modern JSX transform. Extends `@jmlweb/tsconfig-base`.

## ✨ Features

- ⚛️ **Modern JSX**: `jsx: "react-jsx"`, no `React` import needed
- 🌐 **DOM Types**: `DOM` and `DOM.Iterable` libs
- 📦 **Bundler Resolution**: `module: "ESNext"` with `moduleResolution: "bundler"`
- 🔒 **Strict Mode**: inherits every strict flag from the base config

## 📦 Installation

```bash
npm install --save-dev @jmlweb/tsconfig-react @jmlweb/tsconfig-base typescript
```

## 🚀 Quick Start

```json
{
  "extends": "@jmlweb/tsconfig-react",
  "include": ["src"],
  "exclude": ["node_modules", "dist"]
}
```

## 💡 Examples

### Vite app

```json
{
  "extends": "@jmlweb/tsconfig-react",
  "compilerOptions": {
    "noEmit": true
  },
  "include": ["src"]
}
```

### Component library with declarations

```json
{
  "extends": "@jmlweb/tsconfig-react",
  "compilerOptions": {
    "outDir": "./dist",
    "rootDir": "./src",
    "emitDeclarationOnly": true
  },
  "include": ["src"],
  "exclude": ["**/*.test.tsx"]
}
```

## 📋 Configuration Details

Extends [`@jmlweb/tsconfig-base`](../../typescript/base/) and overrides:

| Option             | Value                               | Description              |
| ------------------ | ----------------------------------- | ------------------------ |
| `jsx`              | `react-jsx`                         | Modern JSX transform     |
| `module`           | `ESNext`                            | ES modules for bundlers  |
| `moduleResolution` | `bundler`                           | Bundler-style resolution |
| `lib`              | `["ES2022", "DOM", "DOM.Iterable"]` | ES2022 plus browser APIs |

Everything else (`strict`, `target: ES2022`, `verbatimModuleSyntax`, …) comes from the base config.

`jsx: react-jsx` uses the automatic runtime (React 16.14+ / 17+).

## 🎯 When to Use

- ✅ React libraries and component packages
- ✅ React apps built with Vite, Rsbuild, esbuild or similar bundlers
- ✅ Projects that need DOM types

Next.js: use [`@jmlweb/tsconfig-nextjs`](../../typescript/nextjs/). Node.js only: use [`@jmlweb/tsconfig-node`](../../typescript/node/).

## 🔧 Extending the Configuration

```json
{
  "extends": "@jmlweb/tsconfig-react",
  "compilerOptions": {
    "jsx": "react-jsxdev",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

## 📝 Usage with Scripts

```json
{
  "scripts": {
    "typecheck": "tsc --noEmit"
  }
}
```

```bash
npm run typecheck
```

## 🔄 Migration Guide

### 1.x → 2.0.0

**Breaking:** Node.js `>=22.12.0` is now required (Node.js 18 and 20 are end-of-life).

1. Upgrade Node.js to 22.12.0 or later.
2. Update the package: `npm install --save-dev @jmlweb/tsconfig-react@^2.0.0`.

The `compilerOptions` are unchanged. See the [Changelog](https://github.com/jmlweb/tooling/blob/main/packages/tsconfig-react/CHANGELOG.md).
