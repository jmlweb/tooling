Welcome to **jmlweb-tooling**! This guide will help you get started with our shared configuration packages for modern JavaScript and TypeScript projects.

## What is jmlweb-tooling?

jmlweb-tooling is a collection of shared configuration packages that provide consistent, opinionated settings for popular development tools:

- **Oxfmt** - Fast code formatting with import sorting (recommended)
- **Oxlint** - Fast linting for JavaScript, TypeScript, React and Node.js, with type-aware rules (recommended)
- **Prettier and ESLint** - The previous formatter and linter configurations, in maintenance mode
- **TypeScript** - Strict TypeScript configurations for various project types
- **Testing** - Pre-configured Vitest and Jest setups
- **Build Tools** - Ready-to-use tsdown and Vite configurations
- **Commit Linting** - Conventional Commits enforcement

### Why Use Shared Configurations?

- **Consistency** - Same code style across all your projects
- **Zero Configuration** - Works out of the box with sensible defaults
- **Best Practices** - Based on industry standards and modern conventions
- **Easy Updates** - Update one package to get improvements across all projects
- **Monorepo Friendly** - Designed to work seamlessly in monorepo setups

Browse all available packages in the sidebar navigation or explore specific categories below.

## Prerequisites

Before getting started, ensure you have:

- **Node.js** >= 22.12.0 ([Download](https://nodejs.org/))
- A package manager: **pnpm** (recommended), npm, or yarn

Check your Node.js version:

```bash
node --version
```

If you don't have pnpm installed:

```bash
npm install -g pnpm
```

## Quick Start

Let's set up a new TypeScript project with Oxfmt, Oxlint and TypeScript configurations.

### 1. Install the Formatter

Install the Oxfmt configuration and Oxfmt:

```bash
pnpm add -D @jmlweb/oxfmt-config-base oxfmt
```

Create an `oxfmt.config.ts` file:

```typescript
import baseConfig from '@jmlweb/oxfmt-config-base';
import { defineConfig } from 'oxfmt';

export default defineConfig({
  ...baseConfig,
});
```

Format your code:

```bash
pnpm exec oxfmt
```

### 2. Install the Linter

Install the Oxlint configuration, Oxlint and its type-aware engine:

```bash
pnpm add -D @jmlweb/oxlint-config-base oxlint oxlint-tsgolint
```

Create an `oxlint.config.ts` file:

```typescript
import baseConfig from '@jmlweb/oxlint-config-base';
import { defineConfig } from 'oxlint';

export default defineConfig({
  extends: [baseConfig],
  options: {
    typeAware: true,
  },
});
```

Run Oxlint:

```bash
pnpm exec oxlint
```

### 3. Install TypeScript Configuration

Install the TypeScript configuration:

```bash
pnpm add -D @jmlweb/tsconfig-base typescript
```

Create a `tsconfig.json` file:

```json
{
  "extends": "@jmlweb/tsconfig-base",
  "compilerOptions": {
    "outDir": "dist"
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

Your project is now configured with Oxfmt, Oxlint and TypeScript!

Already using the Prettier and ESLint packages? See [Migrate to Oxc](../guides/migrate-to-oxc/).

## Configuration Hierarchy

jmlweb-tooling packages follow a **base → variant** pattern, allowing you to start with sensible defaults and extend for specific use cases.

### Formatter Configurations

```
@jmlweb/oxfmt-config-base (formatting, import sorting, optional Tailwind CSS class sorting)
```

The Prettier configurations are maintained for existing projects:

```
@jmlweb/prettier-config-base (base formatting rules)
  └── @jmlweb/prettier-config-tailwind (adds Tailwind CSS class sorting)
```

### Linter Configurations

```
@jmlweb/oxlint-config-base (JavaScript and TypeScript linting)
  ├── @jmlweb/oxlint-config-react (adds React, hooks and JSX rules)
  └── @jmlweb/oxlint-config-node (adds Node.js rules)
```

The ESLint configurations are maintained for existing projects, and `eslint-config-astro` remains the way to lint `.astro` files:

```
@jmlweb/eslint-config-base-js (JavaScript linting)
  └── @jmlweb/eslint-config-base (adds TypeScript support)
      ├── @jmlweb/eslint-config-react (adds React and JSX rules)
      ├── @jmlweb/eslint-config-node (adds Node.js specific rules)
      └── @jmlweb/eslint-config-astro (adds Astro framework rules)
```

### TypeScript Configurations

```
@jmlweb/tsconfig-base (strict base configuration)
  ├── @jmlweb/tsconfig-node (Node.js projects)
  ├── @jmlweb/tsconfig-react (React libraries)
  ├── @jmlweb/tsconfig-nextjs (Next.js applications)
  └── @jmlweb/tsconfig-astro (Astro projects)
```

**Example**: Extend `tsconfig-node` for backend services, `tsconfig-nextjs` for Next.js apps.

### Testing Configurations

```
@jmlweb/vitest-config (Vitest with TypeScript and coverage)
@jmlweb/jest-config (Jest with TypeScript support)
```

### Build Tool Configurations

```
@jmlweb/tsdown-config-base (tsdown for building TypeScript packages)
@jmlweb/vite-config (Vite for frontend projects)
@jmlweb/tsup-config-base (deprecated, use tsdown-config-base)
```

## Common Patterns

### New TypeScript Project

Setting up a basic TypeScript project from scratch:

```bash
# Initialize project
mkdir my-project && cd my-project
pnpm init

# Install configurations
pnpm add -D @jmlweb/oxfmt-config-base oxfmt
pnpm add -D @jmlweb/oxlint-config-base oxlint oxlint-tsgolint
pnpm add -D @jmlweb/tsconfig-node typescript

# Create source directory
mkdir src
```

**package.json**:

```json
{
  "name": "my-project",
  "type": "module",
  "scripts": {
    "build": "tsc",
    "lint": "oxlint",
    "format": "oxfmt"
  }
}
```

**tsconfig.json**:

```json
{
  "extends": "@jmlweb/tsconfig-node",
  "compilerOptions": {
    "outDir": "dist"
  },
  "include": ["src/**/*"]
}
```

Add the `oxfmt.config.ts` and `oxlint.config.ts` files from the [Quick Start](#quick-start).

### React TypeScript Project

For a React application with TypeScript:

```bash
# Install dependencies
pnpm add -D @jmlweb/oxfmt-config-base oxfmt
pnpm add -D @jmlweb/oxlint-config-react oxlint oxlint-tsgolint @eslint-react/eslint-plugin eslint-plugin-perfectionist
pnpm add -D @jmlweb/tsconfig-react typescript

# For Vite-based projects
pnpm add -D @jmlweb/vite-config vite
```

**oxlint.config.ts**:

```typescript
import reactConfig from '@jmlweb/oxlint-config-react';
import { defineConfig } from 'oxlint';

export default defineConfig({
  extends: [reactConfig],
  options: {
    typeAware: true,
  },
});
```

**tsconfig.json**:

```json
{
  "extends": "@jmlweb/tsconfig-react",
  "compilerOptions": {
    "outDir": "dist"
  },
  "include": ["src"]
}
```

**vite.config.ts** (if using Vite):

```typescript
import { createReactViteConfig } from '@jmlweb/vite-config';

export default createReactViteConfig();
```

For Tailwind CSS, enable class sorting in `oxfmt.config.ts` with `sortTailwindcss: { stylesheet: './src/index.css' }`.

### Next.js Project

For a Next.js application:

```bash
# Install configurations
pnpm add -D @jmlweb/oxfmt-config-base oxfmt
pnpm add -D @jmlweb/oxlint-config-react oxlint oxlint-tsgolint @eslint-react/eslint-plugin eslint-plugin-perfectionist
pnpm add -D @jmlweb/tsconfig-nextjs typescript
```

**tsconfig.json**:

```json
{
  "extends": "@jmlweb/tsconfig-nextjs",
  "include": ["next-env.d.ts", "**/*.ts", "**/*.tsx", ".next/types/**/*.ts"],
  "exclude": ["node_modules"]
}
```

### Node.js API Project

For a Node.js backend service:

```bash
# Install configurations
pnpm add -D @jmlweb/oxfmt-config-base oxfmt
pnpm add -D @jmlweb/oxlint-config-node oxlint oxlint-tsgolint eslint-plugin-n
pnpm add -D @jmlweb/tsconfig-node typescript
pnpm add -D @jmlweb/vitest-config vitest
```

**oxlint.config.ts**:

```typescript
import nodeConfig from '@jmlweb/oxlint-config-node';
import { defineConfig } from 'oxlint';

export default defineConfig({
  extends: [nodeConfig],
  options: {
    typeAware: true,
  },
});
```

**vitest.config.ts**:

```typescript
import baseConfig from '@jmlweb/vitest-config';
import { defineConfig } from 'vitest/config';

export default defineConfig({
  ...baseConfig,
  test: {
    ...baseConfig.test,
  },
});
```

### Monorepo Setup

For workspace/monorepo dependencies, use the `workspace:*` protocol:

**Root package.json**:

```json
{
  "devDependencies": {
    "@jmlweb/oxfmt-config-base": "workspace:*",
    "@jmlweb/oxlint-config-base": "workspace:*",
    "@jmlweb/tsconfig-base": "workspace:*"
  }
}
```

This allows all packages in the monorepo to share the same configuration versions. See [Monorepos](../guides/migrate-to-oxc/#monorepos) for how Oxlint resolves configs and type-aware rules across packages.

## Extending Configurations

All configurations can be extended to customize for your specific needs:

### Extending Oxfmt

```typescript
// oxfmt.config.ts
import baseConfig from '@jmlweb/oxfmt-config-base';
import { defineConfig } from 'oxfmt';

export default defineConfig({
  ...baseConfig,
  // Override specific options
  printWidth: 100,
  semi: false,
});
```

### Extending Oxlint

```typescript
// oxlint.config.ts
import baseConfig from '@jmlweb/oxlint-config-base';
import { defineConfig } from 'oxlint';

export default defineConfig({
  extends: [baseConfig],
  options: {
    typeAware: true,
  },
  rules: {
    // Override or add specific rules
    'eslint/no-unused-vars': 'warn',
  },
});
```

### Extending TypeScript

```json
{
  "extends": "@jmlweb/tsconfig-base",
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022"],
    "outDir": "dist",
    "rootDir": "src"
  }
}
```

## Package Manager Scripts

Add these common scripts to your `package.json`:

```json
{
  "scripts": {
    "build": "tsc",
    "lint": "oxlint",
    "lint:fix": "oxlint --fix",
    "format": "oxfmt",
    "format:check": "oxfmt --check",
    "test": "vitest",
    "type-check": "tsc --noEmit"
  }
}
```

Run them with:

```bash
pnpm lint        # Check for linting errors
pnpm lint:fix    # Fix auto-fixable errors
pnpm format      # Format all files
pnpm test        # Run tests
```

## Troubleshooting

### Type-Aware Rules Do Not Report

`options.typeAware` must be set in your own `oxlint.config.ts`, and `oxlint-tsgolint` must be installed. Oxlint ignores `options` in configs loaded through `extends`.

### IDE Integration

For VS Code, install the [Oxc extension](https://marketplace.visualstudio.com/items?itemName=oxc.oxc-vscode), which runs both Oxfmt and Oxlint.

Add to `.vscode/settings.json`:

```json
{
  "editor.defaultFormatter": "oxc.oxc-vscode",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.oxc": "always"
  }
}
```

### Package Not Found

If you see `Cannot find package '@jmlweb/...'`:

1. Ensure you've installed the package: `pnpm add -D @jmlweb/package-name`
2. Check the package name is correct (all lowercase, with hyphens)
3. Run `pnpm install` to ensure dependencies are installed
