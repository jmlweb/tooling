# jmlweb-tooling

A collection of shared configuration packages for modern JavaScript and TypeScript projects. These packages provide consistent, opinionated configurations for popular development tools.

## Package Categories

<CardGrid>
  <Card title="Oxfmt" icon="seti:config">

  </Card>
  <Card title="Oxlint" icon="seti:config">
    Fast linting for JavaScript, TypeScript, React and Node.js, with type-aware rules. Recommended for new projects.
  </Card>
  <Card title="Prettier and ESLint" icon="seti:eslint">
    The previous formatter and linter configurations, maintained for existing projects. ESLint still lints Astro files.
  </Card>

  <Card title="Testing" icon="seti:jest">

  <Card title="Build Tools" icon="seti:config">

  </Card>
  <Card title="Commit" icon="approve-check-mark">

  </Card>

## Features

- **Zero Configuration**: Drop-in configurations that work out of the box
- **Opinionated**: Sensible defaults based on industry best practices
- **Extensible**: Easy to override and customize for your specific needs
- **Type-Safe**: Full TypeScript support across all packages
- **Monorepo Friendly**: Designed to work seamlessly in monorepo setups

## Quick Start

All packages are published to npm under the `@jmlweb` scope. Install the configurations you need:

```bash
# Formatter
pnpm add -D @jmlweb/oxfmt-config-base oxfmt

# Linter
pnpm add -D @jmlweb/oxlint-config-base oxlint oxlint-tsgolint

# TypeScript configuration
pnpm add -D @jmlweb/tsconfig-base typescript
```

See [Getting Started](getting-started/) for the setup, or [Migrate to Oxc](guides/migrate-to-oxc/) to move a project from Prettier and ESLint.
