&gt; Shared Prettier configuration for consistent code style across projects.

&gt; 🔧 **Maintenance mode**: dependency and security updates only, no new rules. New projects should use [`@jmlweb/oxfmt-config-base`](../../oxfmt/base/). To migrate, see the [migration guide](https://jmlweb.github.io/tooling/guides/migrate-to-oxc/).

## ✨ Features

- 🎯 **Consistent**: one code style for every project
- 🔧 **Zero config**: sensible defaults out of the box
- 📦 **Extensible**: base for [`@jmlweb/prettier-config-tailwind`](../../prettier/tailwind/)
- 🔀 **Dual format**: ESM and CommonJS builds

## 📦 Installation

```bash
npm install --save-dev @jmlweb/prettier-config-base prettier
```

&gt; 💡 Upgrading? See the [Migration Guide](#-migration-guide).

## 🚀 Quick Start

Create `.prettierrc.mjs` (works for ESM and CommonJS projects):

```javascript
export { default } from '@jmlweb/prettier-config-base';
```

Alternatives:

```json
{
  "prettier": "@jmlweb/prettier-config-base"
}
```

&gt; ⚠️ In projects with `"type": "module"`, the `package.json` field can make Prettier warn `Ignored unknown option { default: ... }` and skip the config. Use `.prettierrc.mjs` instead.

For CommonJS (`.prettierrc.cjs`):

```javascript
module.exports = require('@jmlweb/prettier-config-base');
```

## 📋 Configuration Details

| Option          | Value        | Description                     |
| --------------- | ------------ | ------------------------------- |
| `semi`          | `true`       | Semicolons at end of statements |
| `singleQuote`   | `true`       | Single quotes                   |
| `tabWidth`      | `2`          | 2-space indentation             |
| `trailingComma` | `'all'`      | Trailing commas everywhere      |
| `useTabs`       | `false`      | Spaces, not tabs                |
| `endOfLine`     | `'lf'`       | LF line endings                 |
| `proseWrap`     | `'preserve'` | Keep prose wrapping in Markdown |

## 🎯 When to Use

- ✅ Existing projects already on Prettier
- ✅ Zero-config, consistent formatting
- ✅ A base to extend with your own options

Not for you if:

- Tailwind class sorting: use [`@jmlweb/prettier-config-tailwind`](../../prettier/tailwind/)
- New projects: use [`@jmlweb/oxfmt-config-base`](../../oxfmt/base/)

## 🔧 Extending the Configuration

```javascript
// .prettierrc.mjs
import baseConfig from '@jmlweb/prettier-config-base';

export default {
  ...baseConfig,
  printWidth: 100,
};
```

## 📝 Usage with Scripts

```json
{
  "scripts": {
    "format": "prettier --write .",
    "format:check": "prettier --check ."
  }
}
```

```bash
npm run format        # format all files
npm run format:check  # check without writing
```

2. Update: `npm install --save-dev @jmlweb/prettier-config-base@latest`
